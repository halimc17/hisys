TRANSAKSI BULKING DISPATCH KOMODITI

Modul : Pabrik
Tentang : Transaksi Dispatch Komoditi
Isi :

Langkah-langkah input Dispatch Komoditi :

Masuk ke menu, klik icon kemudian lengkapi form header, seperti contoh di bawah ini :

Kemudian klik tombol Simpan untuk menyimpan data.

Sistem akan menampilkan form rincian, pada form rincian terdapat 4 tab form yaitu, tab Analisa Lab, tab Sounding, tab Segel, tab Porsi Stock, lengkapi data rincian sesuai dengan masing-masing tabnya, seperti contoh berikut :

  1. Tab Analisa Lab

      • Input data analisa lab seperti contoh diatas, kolom No. Berita Acara Analisa akan otomatis terisi saat menyimpan data.
      • Klik tombol Simpan untuk menyimpan data rincian analisa lab.
      • Data yang sudah tersimpan akan muncul pada List Data
      • Klik icon untuk mengedit data analisa lab
      • Klik icon untuk menghapus data analisa lab

  2. Tab Sounding

      • Input data sounding seperti contoh diatas.
      • Klik tombol Simpan untuk menyimpan data rincian sounding.
      • Data yang sudah tersimpan akan muncul pada List Data
      • Klik icon untuk mengedit data sounding
      • Klik icon untuk menghapus data sounding

  3. Tab Segel

      • Input data segel seperti contoh diatas.
      • Klik tombol Simpan untuk menyimpan data rincian segel.
      • Data yang sudah tersimpan akan muncul pada List Data
      • Klik icon untuk mengedit data segel
      • Klik icon untuk menghapus data segel

  4. Tab Porsi Stock

      • Input data porsi stock seperti contoh diatas.
      • Klik tombol Simpan untuk menyimpan data rincian porsi stock.
      • Data yang sudah tersimpan akan muncul pada List Data
      • Klik icon untuk menghapus data porsi stock

    Klik untuk melihat data yang sudah tersimpan List Data, seperti dibawah ini :

    • Klik icon untuk mengedit data dispatch komoditi
    • Klik icon untuk menghapus data dispatch komoditi
    • Klik icon untuk melihat BA Pengapalan dalam format PDF
    • Klik icon untuk posting data dispatch komoditi, jika data telah diposting maka icon akan berubah menjadi warna hijau.

    Fungsi tombol posting ini agar data tersebut tidak dapat diubah ataupun dihapus, dan sekaligus untuk mengurangi saldo fisik pada penerimaan komoditi.
