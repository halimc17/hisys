PEMAKAIAN BARANG

Modul : Pengadaan
Tentang : Pemakaian Barang
Isi :

Langkah-langkah pemakaian barang:

Masuk ke menu, akan terdapat form daftar gudang dan 2 tab yaitu tab Pengeluaran Barang dan tab List Data, sebagai berikut :

Pilih gudang yang dimaksud, Pemilik Barang akan otomatis muncul kemudian klik Simpan. Tombol Ganti digunakan untuk mengganti pilihan gudang.

  1. Tab Pengeluaran Barang
    1. Setelah klik tombol Simpan di atas maka secara otomatis No. Dokumen pengeluaran barang akan terbentuk kemudian isikan Untuk, Penerima, Sub Unit, Catatan dan rincian barang yang dipakai seperti di bawah ini :

      2. Untuk memperoleh kode barang pada rincian, klik pada kode/nama barang maka akan muncul window baru untuk melakukan pencarian barang kemudian isi nama barang dan klik pada barang yang dimaksud. Barang yang akan muncul hanya yang memiliki saldo.

    2. Berikut tampilan setelah memilih barang di atas :

      3. Lengkapi data Jumlah, Blok/Mesin PKS, Kend/AB/Mesin dan Kegiatan. Jika rincian data sudah lengkap maka klik tombol Simpan.

    3. Berikut tampilan data untuk rincian data yang sudah tersimpan :

      4. Jika masih ada barang lain yang diperlukan, bisa diisikan kembali pada form Rincian di atas.

      • Klik icon untuk mengedit/mengubah data detail pengeluaran barang
      • Klik icon untuk menghapus data detail pengeluaran barang
    4. Klik tombol selesai jika barang yang dimaksud sudah selesai diisikan pada form rincian

  2. Tab List Data
    1. Klik Tab List Data maka akan muncul semua transaksi pemakaian barang di gudang. Lakukan pencarian untuk transaksi pemakaian barang yang dimaksud seperti tampilan di bawah ini :

    2. Berikut hasil pencarian transaksi di atas :

      • Klik icon untuk melakukan pemakaian barang
      • Klik icon untuk hapus transaksi pemakaian barang
      • Klik icon untuk melihat Berita Acara Serah Terima Barang dalam format PDF

      Karena transaksi pemakaian barang ini masih belum diposting maka status Berita Acara Serah Terima Barang ini masih "Not Confirm", seperti gambar dibawah ini :

      Lakukan proses posting pada menu Pengadaan - Transaksi - Adm. Gudang - Posting untuk mengubah status tersebut menjadi "Confirm"
