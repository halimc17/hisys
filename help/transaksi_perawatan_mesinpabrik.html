TRANSAKSI PERAWATAN MESIN PABRIK

Modul : Pabrik
Tentang : Transaksi Perawatan Mesin Pabrik
Isi :

Langkah-langkah input Transaksi Perawatan Mesin Pabrik :

  1. Masuk ke menu, klik icon untuk input transaksi perawatan mesin pabrik. Berikut tampilan form header :

    2. Jika form header sudah dilengkapi klik tombol Simpan, untuk menyimpan data.

  2. Setelah disimpan akan muncul form detail sebagai berikut :

    3. Input form detail daftar barang terlebih dahulu, klik icon untuk mencari barang yang dimaksud, berikut tampilan form pencariannya :

    Ketik nama barang yang dicari kemudian klik tombol Cari, setelah daftar nama barang keluar pilih nama barang yang dimaksud dengan cara klik pada nama barang tersebut.

    Setelah selesai input jumlah dan keterangan kemudian klik icon untuk menyimpan data barang, dan data barang tersebut akan masuk dalam list data seperti di bawah ini :

    Klik icon untuk hapus data barang.

    Lakukan lagi langkah awal no.2 untuk menambahkan barang yang lain.

  3. Kemudian input data detail pekerjaan, klik pada subform "List Pekerjaan" maka akan muncul form sebagai berikut :

    4. Lengkapi form tersebut, setelah selesai tekan tombol Simpan untuk menyimpan data.

    Data pekerjaan tersebut akan masuk dalam list data seperti di bawah ini :

  4. Kemudian input data detail karyawan, klik pada subform “Karyawan” maka akan muncul form sebagai berikut :

    5. Lengkapi form tersebut, setelah selesai tekan tombol Simpan untuk menyimpan data.

    Data karyawan tersebut akan masuk dalam list data seperti di bawah ini :

    Proses Input Selesai.

  5. Klik icon untuk melihat semua list data perawatan mesin pabrik.
  6. Terdapat fasilitas pencarian untuk data perawatan mesin pabrik seperti di bawah ini :

    7. Pencarian ini berdasarkan no. transaksi dan/atau tanggal kemudian klik tombol Cari.

  7. Berikut hasil pencariannya :

  8. Klik icon untuk edit data perawatan mesin pabrik.
  9. Klik icon untuk hapus data perawatan mesin pabrik.
  10. Klik icon untuk posting data perawatan mesin pabrik.
  11. Klik icon untuk melihat data perawatan mesin pabrik.
