TRANSAKSI PACKING LIST

Modul : Pengadaan
Tentang : Transaksi Packing List
Isi :

Langkah-langkah input Transaksi Packing List :

Masuk ke menu, akan terdapat 2 Tab yaitu Tab Form dan Tab List Data seperti di bawah ini :

  1. Tab Form
    1. Lengkapi data Form dengan benar, seperti contoh berikut :

      2. No. Transaksi akan terbentuk secara otomatis.

    2. Kemudian muncul Form rincian untuk mencari No. PO atau kode barang, klik icon untuk melakukan pencarian data:

      3. Berikut tampilan daftar Pencarian berdasarkan No PO : (perhatikan Note yang tampil pada pencarian No.PO)

      Pilih PO yang dimaksud dengan mengklik baris pada no PO tersebut.

      Atau bisa juga dengan pencarian berdasarkan kode barang, dengan klik icon pada kode barang untuk menampilkan form pencarian kode barang, seperti dibawah ini :

      Lengkapi isian tersebut dengan benar kemudian klik tombol Simpan

    3. Sistem akan menampilkan data detail dari pencarian no PO atau Kode Barang tersebut dalam form berikut :

      • Klik icon untuk menyimpan data tersebut
      • Klik icon untuk menghapus data
      • Jika ingin mengubah data klik tombol Ubah setelah selesai mengubah data klik tombol Simpan, kemudian tekan tombol Selesai.
  2. Tab List Data

      3. Klik List Data, untuk melihat data yang telah diinput sebelumnya, terdapat form untuk mencari data berdasarkan Kode PT, Periode dan No.Transaksi seperti dibawah ini maka data yang dicari akan otomatis keluar :

      • Klik icon untuk edit data Packing List.
      • Klik icon untuk menghapus data Packing List
      • Klik icon untuk memposting data Packing List, Jika data sudah diposting maka warna icon berubah menjadi hijau
      • Klik icon untuk melihat data Packing List dalam format PDF
