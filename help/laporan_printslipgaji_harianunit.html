LAPORAN PRINT SLIP GAJI HARIAN UNIT

Modul : SDM
Tentang : Laporan Print Slip Gaji Harian Unit
Isi :

Langkah-langkah melihat Laporan Print Slip Gaji Harian Unit :

Masuk ke menu, akan muncul 3 form untuk pencarian data slip gaji harian, seperti berikut :

  1. Slip Gaji Harian Per Periode

    2. Pilih periode, bagian dan tipe karyawan kemudian klik tombol Preview seperti di bawah ini :

    Laporan ini dapat dibuka dalam format PDF dan Excel dengan klik tombol PDF atau tombol Excel di atas.

    Berikut contoh tampilan dari Laporan Print Slip Gaji Harian per Periode :

  2. Slip Gaji Harian Per Karyawan

    3. Pilih periode dan nama karyawan, kemudian klik tombol Preview seperti di bawah ini :

    Laporan ini dapat dibuka dalam format PDF dengan klik tombol PDF di atas.

    Berikut contoh tampilan dari Laporan Print Slip Gaji Harian per Karyawan :

  3. Slip Gaji Harian per Station

    4. Pilih periode, nama unit, nama bagian, dan tipe karyawan, kemudian klik tombol Preview seperti di bawah ini :

    Laporan ini dapat dibuka dalam format PDF dan Excel dengan klik tombol PDF atau tombol Excel di atas.

    Berikut contoh tampilan dari Laporan Print Slip Gaji Harian per Station :
