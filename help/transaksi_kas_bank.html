KEUANGAN

Sub Menu : "Kas Bank'

Ini adalah menu Transaksi berupa input Kas dan Bank yang diperuntukkan pada bagian Keuangan :

  1. Arahkan kursor anda ke menu Keuangan - Transaksi - Kas dan Bank seperti di bawah ini :

  2. Klik icon untuk membuat data Transaksi Kas dan Bank yang baru berikut tampilan Form untuk menambahkan detail dan lengkapi data seperti contoh dibawah ini jika user memiliki data yang lebih lengkap dapat mengisi keterangan yang lain
    3.  

  3. Nomor Transaksi : Otomatis by system
  4. Unit Kerja : Sesuai lokasi tugas user
  5. Nomor Akun : pilih kode dan nama akun
  6. Tanggal : Isikan tanggal transaksi
  7. Mata Uang : Pilih mata uang
  8. Tipe transaksi : Pilih keluar untuk pembayaran (Masuk = Penerimaan ; Keluar = Pembayaran)
  9. Jumlah : Isikan nilai uang yang akan dibayarkan sesuai nilai invoice
  10. Dibayar dengan : Pilih yang sesuai
  11. Keterangan : Isikan keterangan tentang pembayaran apa?
  12. Hutang unit : Abaikan, hanya diisi jika ada pembayaran dari RO/HO namun bebannya di unit (contoh : pembayaran PO/BAPP)
  13. Pemilik Hutang : kosongkan
  14. No. Akun Hutang : kosongkan

    15. Setelah semua terisi klik tombol dan kemudian isikan detailnya sebagai berikut :

  15. Pada form ini terdapat icon untuk mencari data dengan mengetik kata kunci pencarian tersebut seperti contoh dibawah ini, isi kolom keterangan pencarian kemudian klik search silahkan pilih akun mana yang akan digunakan, icon pencarian ini berlaku untuk kolom yang lain :

    16. Perhatikan, terdapat Tools untuk menambahkan Detail Kas dan Bank berdasarkan Invoice dan data Memorial dengan klik Tools berikut silahkan cari dan pilih untuk menambahkan detail data akan secara otomatis masuk ke Tabel Kas dan Bank

    Sedangkan untuk menambahkan detail Tabel Kas dan Bank secara manual berikut tampilan Form nya silahkan lengkapi Form Detail seperti dibawah ini :

  16. Kode : isi pilihan sesuai tipe transaksi di header
  17. No. Invoice : abaikan jika / hanya pembayaran melalui invoice (contoh, pembuatan PO/BAPP)
  18. Nomor akun : pilih no akun
  19. Arus Kas : pilih nomor arus kas
  20. Mata Uang : mata uang dikunci berdasarkan pilihan di header
  21. Kurs : kurs otomatis diambil berdasarkan mata uang dan sumber dari menu: Setup - Mata Uang dan Kurs (yang diisi oleh Dept Finance di Kantor Pusat)
  22. Keterangan : berisi keterangan yang menjelaskan pembayaran untuk
  23. Jumlah : jumlah uang
  24. Segmen : abaikan
  25. Kode kegiatan : hanya diisi jika nomor akun pekerjaan (contoh 126 xxx, 611xxxx, 621xxxx)
  26. Aktiva dalam kontruksi : abaikan hanya diisi jika pembayaran akan dibebankan terhadap suatu project (Traksi - Transaksi- Project)
  27. Kode Barang : abaikan, diisi jika misalkan karyawan melakukan pengambilan barang digudang, Contoh : Solar namun akan dibebankan sebagai Piutang
  28. No. Induk Karyawan : abaikan, diisi jika kode akun transaksi berupa Piutang Karyawan
  29. Kode Pelanggan : hanya diisi jika akun berhubungan dengan Pelanggan/Customer
  30. Kode supplier : hanya diisi jika akun berhubungan dengan Supplier
  31. Kode kendaraan : hanya diisi jika akun transit (akun = 4xxxxxx)
  32. Kode blok : hanya diisi jika nomor akun pekerjaan (contoh 126xxxx, 611xxxx, 621xxxx)
  33. No Dokumen : hanya berisi jika ada transaksi pengembalian uang muka, cari nomor transaksi uang muka
  34. Hutang unit : abaikan, hanya diisi jika ada pembayaran dari RO/HO namun bebannya di unit (contoh pembayaran PO/BAPP)

Setelah semua terisi klik tombol dan kemudian isikan detailnya sebagai berikut :

  • Klik icon untuk mengedit data kas dan bank
  • Klik icon untuk menghapus data kas dan bank, perlu diingat untuk data yang dapat dihapus hanya data yang belum diposting
  • Catatan : Penginputan pada form detail bisa lebih dari satu akun
