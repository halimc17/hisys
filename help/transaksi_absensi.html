TRANSAKSI ABSENSI

Modul : SDM
Tentang : Transaksi Absensi
Isi :

Langkah-langkah input Transaksi Absensi :

Dalam tampilan form absensi terdapat tabel informasi untuk pengisian HK, seperti berikut :

  1. Masuk ke menu, klik icon untuk membuat transaksi absensi baru.
  2. Berikut tampilan form Header pengisian absensi :

  3. Pilih Kode Organisasi, tanggal dan periode kemudian klik tombol Simpan untuk menyimpan data atau klik tombol Batal untuk membatalkan.
  4. Setelah Header disimpan maka akan muncul form rincian seperti di bawah ini :

  5. Lengkapi data seperti di atas kemudian klik icon untuk menyimpan rincian data. Jika sudah selesai mengisi rincian data, klik tombol Selesai.
  6. Data rincian yang sudah tersimpan akan muncul pada form Data Tersimpan di bawah ini :

      • Klik icon untuk edit rincian data absensi.
      • Klik icon untuk hapus rincian data absensi.
  7. Klik icon untuk melihat semua list data absensi.

    8. Terdapat fasilitas pencarian berdasarkan Unit Kerja dan Tanggal seperti di bawah ini :

  8. Klik tombol Cari untuk melakukan pencarian, berikut hasil pencariannya :

  9. Klik icon untuk edit rincian data absensi (data Header tidak dapat diedit).
  10. Klik icon untuk hapus data absensi.
  11. Klik icon untuk melihat data absensi dalam format PDF.
