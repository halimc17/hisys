BA PENCUCIAN TANGKI

Modul : Pabrik
Tentang : Transaksi Berita Acara Pencucian Tangki
Isi :

Langkah-langkah input BA Pencucian Tangki :

  1. Masuk ke menu, akan terdapat 2 tab yaitu form dan laporan seperti di bawah ini :

  2. Untuk tab form lengkapi data kemudian klik tombol Simpan untuk menyimpan data. Data yang sudah tersimpan akan muncul pada List Data, seperti dibawah ini :

  3. Pada menu ini terdapat search engine untuk mencari data berdasarkan nama barang dan tanggal.
  4. Klik icon untuk mengedit data BA Pencucian Tangki
  5. Klik icon untuk menghapus data BA Pencucian Tangki
  6. Klik tab Laporan untuk melihat laporan BA Pencucian Tangki, dengan terlebih dahulu input kriteria data yang ingin ditampilkan pada laporan tersebut :

    7. Klik tombol Preview untuk menampilkan data seperti dibawah ini

    Laporan BA Pencucian Tangki dapat juga dibuka dalam format Excel dengan klik tombol Excel.
