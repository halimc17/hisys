DAFTAR IJIN/CUTI

Modul : SDM
Tentang : Persetujuan Ijin/Cuti
Isi :

Langkah-langkah Persetujuan Ijin/Cuti oleh Atasan :

  1. Masuk ke menu, lengkapi form persetujuan ijin/cuti seperti di bawah ini :

    2. Klik tombol Preview kemudian sistem akan menampilkan daftar ijin/cuti seperti berikut :

  2. Klik tombol Disetujui untuk menyetujui pengajuan cuti tersebut atau klik tombol Ditolak untuk menolak

    3. Sistem akan memberikan informasi bahwa data pengajuan cuti berhasil disetujui.

  3. Data pengajuan ijin/cuti sudah disetujui atasan tetapi masih menunggu persetujuan dari pihak HRD :

  4. Klik tombol Excel untuk melihat semua list data ijin/cuti dalam format Excel.
  5. Klik icon untuk cetak Surat Ijin/Cuti dalam format PDF.
