TRANSAKSI BULKING PENGIRIMAN KOMODITI

Modul : Pabrik
Tentang : Transaksi Pengiriman Komoditi
Isi :

Langkah-langkah input Pengiriman Komoditi :

  1. Masuk ke menu dengan klik icon kemudian lengkapi form header pengiriman komoditi, seperti contoh di bawah ini :

  2. Kemudian klik tombol Simpan untuk menyimpan data header. Setelah disimpan, sistem akan menampilkan form detail seperti berikut :

  3. Isi form detail dengan cara cari/pilih no tiket timbangan, setelah dipilih kolom komoditi dan berat bersih akan terisi secara otomatis sesuai dengan data yang terekam pada no tiket tersebut. Klik icon untuk menyimpan data detail.

  4. Data detail yang tersimpan akan muncul pada list data detail seperti gambar diatas.
  5. Klik icon untuk menghapus data detail pengiriman komoditi
  6. Setelah selesai melakukan input data detail tekan tombol Selesai kemudian sistem akan menampilkan konfirmasi penyimpanan sebagai berikut :

  7. Klik OK, sistem akan menampilkan List Data pengiriman komoditi, seperti dibawah ini :

      • Klik icon untuk mengedit data pengiriman komoditi
      • Klik icon untuk menghapus data pengiriman komoditi
      • Klik icon untuk melihat data detail pengiriman komoditi
      • Klik icon untuk posting/mengunci data agar data tidak dapat diubah ataupun dihapus.

  8. Pada menu ini, terdapat search engine untuk mencari data pengiriman komoditi yang telah disimpan, sebagai berikut :

  9. Masukkan kriteria data yang ingin dicari, kemudian klik tombol Cari, berikut hasil pencariannya :
