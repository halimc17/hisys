PEMBAGIAN CATU

Modul : SDM
Tentang : Transaksi Pembagian Catu
Isi :

  1. Masuk ke menu, berikut tampilan form pembagian catu :

    2. Masukkan ketentuan besarnya rupiah per kg, kemudian klik tombol Tampilkan untuk melihat semua data pembagian catu, seperti dibawah ini :

  2. Setelah data tampil, klik tombol Simpan.

  3. Setelah klik tombol Simpan, form akan mengarahkan ke Tab List untuk proses posting data pembagian catu.

  4. Klik icon untuk melihat list data pembagian catu dalam format Excel.
  5. Klik icon untuk posting data pembagaian catu agar masuk ke dalam jurnal.
