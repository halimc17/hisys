MUTASI BARANG ANTAR GUDANG

Modul : Pengadaan
Tentang : Mutasi Barang Antar Gudang
Isi :

Langkah-langkah melakukan Mutasi Barang Antar Gudang :

Masuk ke menu, akan terdapat form daftar gudang dan 2 tab yaitu tab Mutasi Barang dan tab List Data.

Pilih gudang yang dimaksud, Pemilik Barang akan otomatis muncul kemudian klik Simpan. Tombol Ganti digunakan untuk mengganti pilihan gudang.

  1. Tab Mutasi Barang
    1. Setelah klik tombol Simpan di atas maka secara otomatis No. Dokumen mutasi barang akan terbentuk kemudian isikan Tanggal, Gudang Tujuan, Catatan, Surat Jalan (Jika ada) dan rincian data barang yang akan dimutasikan seperti di bawah ini :

      2. Untuk memperoleh kode barang pada rincian, klik pada kode/nama barang maka akan muncul window baru untuk melakukan pencarian barang kemudian isi nama barang dan klik pada barang yang dimaksud. Barang yang akan muncul hanya yang memiliki saldo.

      Berikut tampilan setelah memilih barang di atas :

      Lengkapi data Jumlah barang klik tombol Simpan.

    2. Berikut tampilan data untuk rincian data yang sudah tersimpan :

      3. Jika masih ada barang lain yang diperlukan, bisa diisikan kembali pada form Rincian di atas.

      Klik icon untuk menghapus data detail mutasi barang

    3. Klik tombol Selesai jika barang yang dimaksud sudah selesai diisikan pada form rincian.

  2. Tab List Data
    1. Klik Tab List Data maka akan muncul semua transaksi mutasi barang. Lakukan pencarian untuk transaksi mutasi barang yang dimaksud seperti tampilan di bawah ini :

    2. Berikut hasil pencarian transaksi di atas :

      • Klik icon untuk hapus data mutasi barang.
      • Klik icon untuk melihat Dokumen Mutasi Barang dalam format PDF.

      Karena transaksi mutasi barang ini masih belum diposting maka status Dokumen Mutasi Barang ini masih "Not Confirm", seperti gambar dibawah ini :
