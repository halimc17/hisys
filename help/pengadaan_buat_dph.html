RIWAYAT PERBANDINGAN HARGA

Modul : Pengadaan
Tentang : Riwayat Perbandingan Harga
Isi :

Langkah-langkah Pembuatan Perbandingan Harga :

  1. Buat Baru
    1. Klik angka pada kolom list job, untuk membuat perbandingan harga, seperti gambar berikut :

    2. Sistem akan menampilkan daftar barang, pilih barang apa saja yang akan dibuatkan perbandingan harganya dengan centang pada check box di bawah ini :

      3. Kemudian klik tombol Lanjut.

    3. Sistem akan menampilkan form daftar supplier, pilih supplier mana saja yang akan dijadikan sebagai perbandingan harga barang, seperti contoh berikut :

      4. Klik tombol Add Data, data supplier akan tersimpan dalam list data.

      Klik tombol Selesai, untuk melanjutkan ke proses selanjutnya.

      Sistem akan menampikan form perbandingan harga, sebagai berikut :

      Lengkapi form di atas kemudian klik tombol Simpan.

  2. List Data
    1. Klik icon untuk melihat list data Perbandingan harga :

    2. Klik icon untuk mengubah data perbandingan harga
    3. Klik icon untuk menambahkan data supplier
    4. Klik icon untuk menghapus data perbandingan harga
    5. Klik icon untuk posting pemenang/supplier yang dipilih dalam tender
    6. Klik icon Pertama untuk mencetak detail data perbandingan harga per supplier
    7. Klik icon Kedua untuk mencetak header data perbandingan harga
    8. Klik icon untuk melihat Perbandingan harga dalam format Excel.
  3. Fasilitas Pencarian
    1. Pencarian berdasarkan No Transaksi Perbandingan Harga dan tanggal kemudian klik tombol Cari:

    2. Berikut hasil pencariannya :
