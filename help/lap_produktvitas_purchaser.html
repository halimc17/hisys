LAPORAN PRODUKTIVITAS PURCHASER

Modul : Pengadaan
Tentang : Laporan Produktivitas Purchaser
Isi :

Langkah-langkah melihat Laporan Produktivitas Purchaser :

  1. Masuk ke menu maka akan muncul tampilan di bawah ini :

    2. Pilih nama perusahaan dan periode, kemudian klik tombol Preview untuk menampilkan laporan.

    Laporan ini dapat dibuka dalam format Excel dengan klik tombol Excel di atas.

  2. Berikut tampilan laporan produktivitas purchaser :

    3. Laporan produktivitas purchaser berfungsi untuk menampilkan total Permintaan Pembelian (PP), Total Purchase Order (PO) per minggu, Total PO sebulan, dan Total PP yang masih outstanding.

  3. Detail dari laporan ini dapat dilihat dengan klik totalan dari purchaser, seperti contoh di bawah ini :

    4. Detail ini dapat dibuka dalam format Excel dengan klik icon
