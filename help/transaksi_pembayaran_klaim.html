TRANSAKSI PEMBAYARAN KLAIM

Modul : SDM
Tentang : Transaksi Pembayaran Klaim
Isi :

Langkah-langkah input Transaksi Pembayaran Klaim :

  1. Masuk ke menu, lengkapi form pencarian seperti di bawah ini :

    2. Kemudian akan muncul list data dengan kriteria yang dimasukkan, sebagai berikut :

  2. Klik icon untuk melihat detail data seperti di bawah ini :

  3. Jika akan melakukan pembayaran klaim, klik icon untuk menampilkan nilai klaim pada kolom verifikasi HRD, pastikan tanggal verifikasi HRD sudah sesuai kemudian klik icon untuk menyimpan pembayaran klaim.

  4. Jika jenis klaim pada data tersebut adalah Rumah Sakit, maka list data pembayaran klaim akan menampilkan tombol posting pada kolom Aksi setelah proses simpan data, seperti gambar di bawah ini :

  5. Lakukan proses posting untuk memasukkan data klaim tersebut ke dalam jurnal, dengan klik pada tombol , jika data sudah diposting tombol tersebut akan berubah menjadi warna hijau

  6. Kolom Dibayar dan Tanggal Bayar akan muncul datanya setelah proses pembayaran di menu kasbank dilakukan, seperti contoh berikut :

  7. Proses Selesai
