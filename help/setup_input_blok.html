INPUT BLOK

Modul : Setup 
Tentang : Input Blok
Isi :

Langkah-langkah input blok :

1. Masuk ke menu maka akan muncul form pencarian data seperti di bawah ini:

Setelah memilih Kebun dan Afdeling kemudian klik tombol Cari, maka akan muncul form pengisian blok dan list blok yang sudah ada.

2. Berikut tampilan form pengisian blok:

Lengkapi pengisian form seperti contoh di atas, setelah selesai klik tombol Simpan.

3. Setelah disimpan, maka data akan muncul pada list data di bawah ini:

  • Klik icon untuk mencetak/melihat data blok dalam format Pdf.
  • Klik icon untuk mengedit data blok.
  • Klik icon untuk menghapus data blok.
