Modul : Pengadaan
Tentang : Laporan Pembelian Terakhir
Isi :

Langkah-langkah melihat Laporan Pembelian Terakhir :

  1. Masuk ke menu, pilih kelompok barang, nama barang (nama barang dapat pilih seluruhnya atau pilih dari drop down nama barang atau dengan klik icon untuk melakukan pencarian berdasarkan nama barang), pilih lokasi pembelian dan periode, seperti contoh tampilan berikut :

    2. Kemudian klik tombol Preview untuk menampilkan laporan.

  2. Berikut tampilan laporan pembelian terakhir :

    3. Laporan ini juga dapat dibuka dalam format Excel dengan klik tombol Excel di atas.
