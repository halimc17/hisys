Langkah-langkah melihat Daftar Supplier :

Masuk ke menu akan terdapat 2 Tab seperti di bawah ini :

  1. Tab Supplier, Kontraktor, Transporter

    2. Masuk ke menu, Pilih Nama Supplier, Tipe dan Kode Kelompok kemudian klik tombol Preview untuk menampilkan daftar supplier:

    Berikut tampilan daftar supplier :

    Laporan ini dapat dilihat dalam format Excel dengan klik tombol Excel

  2. Tab Buyer

    3. Pilih Nama Buyer dan Komoditi kemudian klik tombol Preview untuk menampilkan daftar buyer:

    Berikut tampilan daftar buyer :

    Laporan ini dapat dilihat dalam format Excel dengan klik tombol Excel
