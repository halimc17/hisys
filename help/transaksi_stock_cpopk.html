TRANSAKSI STOK CPO/PK

Modul : Pabrik
Tentang : Transaksi Stok CPO/PK
Isi :

Langkah-langkah input Transaksi Stok CPO/PK :

  1. Masuk ke menu, klik icon untuk input transaksi Stok CPO/PK.

    2. Lengkapi data seperti di atas kemudian klik tombol Simpan untuk menyimpan data.

  2. Data yang sudah tersimpan akan muncul pada List Data atau klik icon untuk melihat semua list data.
  3. Terdapat fasilitas pencarian untuk data persediaan hasil seperti di bawah ini :

    4. Pencarian ini berdasarkan no. transaksi kemudian klik tombol Cari.

  4. Berikut hasil pencariannya :

  5. Klik icon untuk mencetak semua list data stok CPO/PK.
  6. Klik icon untuk melihat semua list data stok CPO/PK dalam format PDF.
  7. Klik icon untuk edit data stok CPO/PK.
  8. Klik icon untuk hapus data stok CPO/PK.
