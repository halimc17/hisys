Sub Menu : "Jurnal Memorial'

Ini adalah menu Transaksi berupa input Jurnal yang diperuntukkan untuk bagian Keuangan :

  • Arahkan kursor anda ke menu Keuangan - Transaksi - Jurnal Memorial seperti di bawah ini :

  • Klik icon untuk menambahkan header baru. Berikut tampilan form header setelah klik icon tambah header:
    •  

    Lengkapi data Kode Jurnal, Tanggal, No. Dokumen, dan Mata Uang seperti di atas kemudian klik tombol Simpan.

  • Setelah klik tombol Simpan maka akan terbentuk No. Jurnal secara otomatis dan muncul Form Jurnal Detail. Berikut tampilannya :

  • Lengkapi data form jurnal detail di atas kemudian klik tombol Simpan, setelah klik tombol Simpan maka jurnal detail akan tersimpan dan muncul pada Tabel Jurnal Detail seperti di bawah ini :

    • Tersedia form aplikasi pencarian data untuk beberapa item pengisian klik icon untuk memunculkan form, sebagai salah satu contoh adalah Form pencarian kode akun seperti dibawah ini. Ketik kata kunci untuk melakukan pencarian lalu klik tombol search :

  • Setelah klik tombol Simpan maka jurnal detail akan tersimpan dan muncul pada Tabel Jurnal Detail seperti di bawah ini :

  • Lakukan kembali langkah no. 3 untuk membuat jurnal kredit pada form jurnal detail sehingga pada Tabel Jurnal Detail akan terdapat jurnal debet dan kredit seperti di bawah ini :

  • Sampai langkah ini, jurnal memorial sudah selesai dibuat. Agar detail data Debet dan Kredit masuk ke Header List klik kanan kemudian klik this frame lalu reload frame

    • Maka data akan masuk ke Header List secara otomatis

  • Untuk memastikan jurnal balance, lihat pada daftar header untuk no. jurnal yang dimaksud kemudian arahkan kursor pada baris jurnal yang dimaksud pada kolom Debet atau Kredit seperti di bawah ini

    Jika sudah balance maka selisih 0, jika belum balance maka baris jurnal tersebut akan berwarna merah dan saat kursor diarahkan akan muncul jumlah selisihnya seperti di bawah ini :

  • Lakukan langkah berikut untuk edit data header jurnal :
    1. Klik pada baris jurnal yang akan diedit seperti dibawah ini.

    2. Setelah klik jurnal yang dimaksud maka data header tersebut akan muncul pada form header di bawah ini :

    Klik tombol Simpan setelah selesai edit data header.

  • Lakukan langkah berikut untuk edit data header jurnal :
      1. Klik pada baris jurnal yang akan diedit seperti dibawah ini.

      2. Setelah klik jurnal yang dimaksud maka data header tersebut akan muncul pada form header di bawah ini :

      3. Klik icon di atas untuk edit detail jurnal :
      4. Klik tombol Simpan setelah selesai edit detail jurnal
      5. Klik icon untuk hapus detail jurnal :
      6. Lakukan langkah berikut untuk hapus header jurnal : Hapus terlebih dahulu detail jurnal kemudian hapus header jurnal dengan klik icon pada daftar header.  Jika detail jurnal belum dihapus maka header jurnal tidak dapat dihapus
