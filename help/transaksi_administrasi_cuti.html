TRANSAKSI ADMINISTRASI CUTI

Modul : SDM
Tentang : Transaksi Administrasi Cuti
Isi :

Langkah-langkah input Transaksi Administrasi Cuti :

Masuk ke menu, akan muncul form untuk pencarian data cuti, tab Header dan tab Rincian seperti di bawah ini :

  1. Form Pencarian Data Cuti
    1. Masukkan kriteria pencarian data seperti Unit Kerja, Tipe Karyawan, dan Periode kemudian tekan tombol Proses.

      2. Jika belum diproses maka saat klik tombol Lihat, tidak akan ada data yang muncul pada tab header.

  2. Tab Header
    1. Data hak cuti karyawan akan muncul seperti di bawah ini, kemudian klik tombol simpan :.

    2. Setelah data diproses akan muncul form cuti sebagai berikut :

    3. Klik icon untuk menyimpan data header cuti.

  3. Tab Rincian
    1. Klik icon untuk memasukan data pemakaian cuti, maka akan muncul form pemakaian data cuti pada tab Rincian, seperti dibawah ini :

    2. Lengkapi data seperti diatas, kemudian tekan tombol Simpan untuk menyimpan data. Data yang tersimpan akan muncul pada list data dibawah ini :

    3. Klik icon untuk menghapus data detail cuti.
