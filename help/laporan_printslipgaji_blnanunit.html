Langkah-langkah melihat Laporan Print Slip Gaji Bulanan Unit :

Masuk ke menu, akan muncul 3 form untuk pencarian data slip gaji bulanan, seperti berikut :

  1. Slip Gaji Bulanan Per Periode

    2. Pilih periode, nama bagian dan tipe karyawan kemudian klik tombol Preview seperti di bawah ini :

    Laporan ini dapat dibuka dalam format PDF dan Excel dengan klik tombol PDF atau tombol Excel di atas.

    Berikut tampilan dari Laporan Print Slip Gaji Bulanan per Periode :

  2. Slip Gaji Bulanan per Karyawan

    3. Pilih periode dan nama karyawan, kemudian klik tombol Preview seperti di bawah ini :

    Laporan ini dapat dibuka dalam format PDF dengan klik tombol PDF di atas.

    Berikut contoh tampilan dari Laporan Print Slip Gaji Bulanan per Karyawan :

  3. Slip Gaji Bulanan per Afdeling

    4. Pilih nama unit, periode, nama bagian, dan tipe karyawan, kemudian klik tombol Preview seperti di bawah ini :

    Laporan ini dapat dibuka dalam format PDF dan Excel dengan klik tombol PDF atau tombol Excel di atas.
