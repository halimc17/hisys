Isi :

Langkah-langkah melihat Laporan Penerimaan-Pengeluaran Per Barang :

Masuk ke menu akan terdapat 2 Tab seperti di bawah ini :

  1. Tab Laporan Penerimaan/masuk Barang

    2. Masuk ke menu, Pilih nama unit, tanggal dan nama supplier kemudian klik tombol Preview untuk menampilkan laporan:

    Berikut tampilan dari Laporan Penerimaan/masuk Barang :

    Laporan ini dapat dilihat dalam format Excel dengan klik tombol Excel

  2. Tab Laporan Pengeluaran Barang

    3. Pilih Nama Unit dan Tanggal kemudian klik tombol Preview untuk menampilkan laporan:

    Berikut tampilan dari Laporan Pengeluaran Barang :

    Laporan ini dapat dilihat dalam format Excel dengan klik tombol Excel
