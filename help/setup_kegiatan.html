Langkah-langkah Setup Kegiatan :

  1. Masuk ke menu, lengkapi data seperti di bawah ini kemudian klik tombol Simpan :

  2. Data kegiatan yang sudah tersimpan akan muncul pada List Data di bawah ini :

    • Klik icon untuk melihat List Data Kegiatan dalam format PDF.
    • Klik icon untuk mencetak List Data Kegiatan.
    • Klik icon untuk edit data kegiatan.
    • Klik icon untuk hapus data kegiatan.
    • Klik icon untuk edit norma kegiatan, sistem akan menampilkan popup norma kegiatan, sebagai berikut :

    • Cari nama barang yang akan ditempel pada kegiatan tersebut, dengan cara klik tombol Cari, kemudian masukkan nama barang klik setelah muncul klik pada nama barang tersebut.
    • Klik icon untuk menyimpan norma kegiatan
    • Klik icon untuk hapus data norma kegiatan
