TRANSAKSI POTONGAN

Modul : SDM
Tentang : Transaksi Potongan
Isi :

Langkah-langkah input Transaksi Potongan :

  1. Masuk ke menu, klik icon untuk buat baru transaksi data potongan, berikut tampilan form header potongan :

    2. Lengkapi data seperti di atas kemudian klik tombol Simpan untuk menyimpan data header.

  2. Setelah header disimpan maka akan muncul form detail seperti di bawah ini :

    3. Lengkapi form tersebut, kemudian klik icon untuk menyimpan data detail potongan. Ulangi langkah ini jika diperlukan. Setelah selesai klik tombol Selesai.

  3. Data detail potongan yang sudah tersimpan akan muncul pada Tabel Detail di bawah ini :

      • Klik icon untuk edit data detail potongan.
      • Klik icon untuk hapus data detail potongan.

  4. Klik icon untuk melihat semua list data header potongan.
  5. Terdapat fasilitas pencarian berdasarkan keterangan seperti di bawah ini :

    6. Isikan kriteria pencarian seperti diatas, kemudian klik tombol Cari untuk melakukan pencarian.

  6. Berikut hasil pencariannya :

  7. Klik icon untuk mengedit/menambahkan data potongan.
  8. Klik icon untuk hapus data header potongan.
  9. Klik icon untuk melihat list data potongan dalam format PDF.
