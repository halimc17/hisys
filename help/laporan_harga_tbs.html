LAPORAN HARGA TBS

Modul : Pabrik
Tentang : Laporan Harga TBS
Isi :

Langkah-langkah meihat Laporan Harga TBS :

  1. Masuk ke menu, pilih nama pabrik, nama supplier, dan tanggal kemudian klik tombol Preview untuk menampilkan laporan.

    2. Laporan ini dapat dibuka dalam format Excel dengan klik tombol Excel

  2. Berikut tampilan Laporan Harga TBS :

    3. Pada kolom Harga Satuan berwarna merah dikarenakan user belum menginput harga satuan TBS pada menu Pabrik - Setup - Harga TBS. Berikut tampilan laporan harga TBS setelah diinput harga TBSnya:
