Modul : Pengadaan
Tentang : Pembuatan BA Pelaksanaan Pekerjaan
Isi :

Langkah-langkah Pembuatan BA Pelaksanaan Pekerjaan :

  1. Masuk ke menu, lakukan pencarian data sebagai berikut :

    2. Atau bisa juga dengan langsung mencari pada list data kontrak perjanjian kerja seperti dibawah ini :

  2. Klik icon pada kontrak perjanjian kerja di atas untuk mengedit atau membuat BA Pelaksanaan Pekerjaan, berikut tampilannya:

  3. Klik pada data detail di atas, maka akan muncul form detail seperti berikut :

    4. Isikan kelengkapan data realisasinya kemudian klik icon untuk menambah detail realisasi.

  4. Saat klik icon maka data akan tersimpan dan muncul baris baru seperti di bawah ini:

    5. Isikan kembali kelengkapan data realisasinya

  5. Klik icon untuk menyimpan data jika ada perubahan (edit) data.
  6. Klik icon untuk menghapus data.
  7. Klik icon untuk posting data. Jika icon tersebut masih berwarna merah maka data belum diposting sehingga masih bisa diedit atau dihapus, jika sudah berwarna hijau maka data sudah diposting dan tidak dapat diedit lagi.
  8. Klik icon pada list data kontrak perjanjian kerja, untuk melihat data BA pelaksanaan pekerjaan dalam format pdf, seperti berikut :
