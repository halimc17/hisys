Modul : Pengadaan
Tentang : Laporan Status PO
Isi :

Langkah-langkah melihat Laporan Status PO :

Masuk ke menu, akan muncul 2 tab yaitu tab PO Status Report dan tab PO Status Detail :

  1. PO Status Report
    1. Pilih nama perusahaan, periode dan lokasi pembelian kemudian klik tombol Preview untuk menampilkan Laporan seperti di bawah ini :

    2. Berikut tampilan PO Status Report :

      3. Laporan ini juga dapat dibuka dalam format Excel dengan klik tombol Excel di atas.

  2. PO Status Detail
    1. Pilih tanggal, status (Head Office/Local), nama perusahaan dan status diterima (Belum Selesai/Sudah Selesai/Dapat Dikirim/Diterima Gudang), seperti contoh di bawah ini :

      2. Kemudian klik tombol Preview untuk menampilkan laporan.

    2. Berikut tampilan dari PO Status Detail :

      3. Laporan ini juga dapat dibuka dalam format Excel dengan klik tombol Excel di atas.
