LAPORAN ESTIMASI GAJI PER HARI

Modul : SDM
Tentang : Laporan Estimasi Gaji per Hari
Isi :

Langkah-langkah melihat Laporan Estimasi Gaji per hari :

  1. Masuk ke menu, pilih Nama Unit, Afdeling, Tanggal dan Tipe Karyawan, kemudian klik tombol Preview untuk menampilkan laporan.

    2. Laporan ini dapat dibuka dalam format Excel dengan klik tombol Excel di atas.

  2. Berikut tampilan dari Laporan Estimasi Gaji per hari :

    3. Catatan : Data akan tetap muncul walaupun belum melakukan proses gaji, karena angka tersebut masih dalam status estimasi.
