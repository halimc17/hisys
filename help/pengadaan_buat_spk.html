Modul : Pengadaan
Tentang : Pembuatan Kontrak Perjanjian Kerja
Isi :

Langkah-langkah Pembuatan Kontrak Perjanjian Kerja:

  1. Masuk ke menu, klik Buat Baru, maka akan muncul form header kontrak perjanjian kerja sebagai berikut:

  2. Lengkapi data header seperti diatas, setelah selesai klik tombol Simpan untuk kemudian input data pada form detail seperti dibawah ini:

  3. Lengkapi detailnya kemudian klik tombol Simpan maka akan muncul tabel detail hasil inputannya:

    4. Sampai tahap ini, kontrak perjanjian kerja telah selesai dibuat.

    Tekan icon untuk melihat daftar kontrak perjanjian kerja yang sudah dibuat, sebagai berikut :

    • Klik icon untuk edit data kontrak perjanjian kerja.
    • Klik icon untuk hapus data kontrak perjanjian kerja.
    • Klik icon untuk posting data kontrak perjanjian kerja.
    • Klik icon untuk melihat data kontrak perjanjian kerja dalam format Pdf
