LAPORAN BUKU BESAR

Modul : Keuangan
Tentang : Laporan Buku Besar
Isi :

Langkah-langkah melihat Laporan Buku Besar :

  • Masuk ke menu, lengkapi pilihan menu pada form untuk mencari data lalu klik tombol proses :

  • Terdapat pilihan pencarian yaitu form seperti gambar dibawah ini dengan klik icon

  • Ketik nama akun untuk pencarian lalu klik tombol search untuk menampilkan data

  • Jika sudah melengkapi data form berikut adalah tampilan laporan buku besar dalam format HTML:

  • Klik tombol Excel atau klik icon untuk mellihat laporan dalam format Excel.
  • Klik tombol PDF atau klik icon untuk mellihat laporan dalam format PDF.
