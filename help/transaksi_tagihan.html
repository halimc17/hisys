TRANSAKSI TAGIHAN

Modul : Keuangan
Tentang : Transaksi Tagihan
Isi :

PANDUAN PEMBUATAN DAN PEMBAYARAN INVOICE

Syarat :
1. Barang sudah diterima digudang.
2. Sudah dilakukan penerimaan barang dari supplier dari menu [Pengadaan > Transaksi > Administrasi Gudang > penerimaan Barang dari Supplier] sehingga muncul BAPB - Berita Acara Penerimaan Barang.
3. Telah terima invoice dari supplier.

Yang perlu dilakukan di system oleh "Purchasing" adalah masuk ke menu :
Menu :
Keuangan- Transaksi - Tagihan

Klik buat baru untuk input transaksi baru :

Klik icon untuk mencari data supplier, akan muncul form pencarian data seperti dibawah ini :

  • No invoice supplier : otomatis by system
  • No Invoice : masukkan nomor invoice yg di terima dari supplier
  • Perusahaan : hanya muncul nama PT berdasarkan lokasi tugas user
  • Unit : hanya dimunculkan berdasarkan unit dari bagian PT
  • Tanggal terima : adalah tanggal terima invoice dari supplier
  • Keterangan : isi dengan keterangan tambahan
  • Upload Int. Memo : dapat melampirkan Internal Memo mengenai tagihan
  • Jenis : memilih jenis dari invoice
  • No.PO : klik maka akan muncul jendela baru pencarian nomor
  • Supplier : lakukan pencarian dengan form (cth : gbr 2)
  • Nomor Akun : saat memilih nomor supplier maka no. akun akan terisi otomatis
  • Mata uang, nilai invoice : dapat terisi otomatis berdasarkan PO terpilih
  • Jatuh tempo : isikan tanggal jatuh tempo invoice
  • No. Faktur Pajak : isikan nomor faktur pajak supplier
  • Nilai Invoice : dapat diisi secara manual oleh user sesuai nilai invoice tsb
  • Uang Muka : diisikan jika pernah dibayarkan uang muka setelah terisi semua, click simpan dan untuk melihat hasil yang kita buat sebelumnya click pada List Data
  • Pembayaran : dapat dibayarkan melalui kas bank atau jurnal

    • Pada kolom aksi ada tombol Posting ( tombol bulat ), jika belum di posting akan berwarna merah namun ketika sudah di posting akan berubah menjadi hijau, syarat untuk melakukan posting ketika semua syarat invoice sudah lengkap dan sudah siap dibayarkan.
    Note: 
    1. Belum di posting :  Invoice sudah muncul di menu
    Keuangan > Transaksi > Kas Bank [add from invoice] namun masih berwarna merah dan blm bisa di select / pilih (belum siap dibayar, bisa karena alasan bukti pendukung belum siap dll)

    2. Sudah diposting : Invoice sudah muncul di menu
    Keuangan > Transaksi > Kas Bank [add from invoice] dan sudah blm bisa di select / pilih (siap dibayarkan)

    Pada saat pembayaran di kasir :
    Syarat : 
    1. Invoice sudah lengkap hard copy maupun soft copy
