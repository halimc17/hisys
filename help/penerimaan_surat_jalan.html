PENERIMAAN SURAT JALAN

Modul : Pengadaan
Tentang : Pengiriman Internal/Penerimaan Surat Jalan
Isi :

Langkah-langkah input Penerimaan Surat Jalan :

  1. Masuk ke menu, akan terdapat form List Data seperti dibawah ini, :

  2. Lakukan pencarian pada form cari surat jalan dengan menginput Nomor Surat Jalan seperti dibawah ini, lalu klik cari :

  3. Klik icon pada kolom aksi untuk menginput data penerimaan surat jalan
  4. Sistem akan menampilkan form detail, lakukan penginputan data, dengan mengisi Quantitiy barang yang diterimakan, kemudian klik tombol Simpan :

  5. Setelah disimpan kemudian lakukan posting untuk mengakui penerimaan surat kerja dan mengunci data agar tidak dapat diubah
  6. Berikut tampilan data setelah data berhasil di posting, pada tombol aksi akan berubah menjadi status posting
