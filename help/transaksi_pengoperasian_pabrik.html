TRANSAKSI PENGOPERASIAN PABRIK

Modul : Pabrik
Tentang : Transaksi Pengoperasian Pabrik
Isi :

Langkah-langkah input Transaksi Pengoperasian Pabrik :

  1. Masuk ke menu, klik icon untuk input transaksi pengoperasian pabrik. Berikut tampilan form tambah header :

    2. Lengkapi data seperti di atas kemudian klik tombol Simpan untuk menyimpan data header.

  2. Setelah data header tersimpan maka akan muncul form tambah detail seperti di bawah ini :

    3. Klik pada tombol "Add Dari Transaksi Perawatan" untuk mengambil data perawatan mesin.

  3. Setelah muncul data dari transaksi perawatan, centang data yg dipilih lalu klik tombol "Tambahkan ke Detail" untuk menyimpan data detail dan data tersebut akan masuk pada list data, sebagai berikut :

  4. Klik icon untuk menghapus data detail pengolahan pabrik.
  5. Proses Input Selesai

  6. Klik icon untuk melihat semua list data pengolahan pabrik.
  7. Terdapat fasilitas pencarian untuk data pengolahan pabrik seperti di bawah ini :

    8. Isikan no.pengolahan kemudian klik tombol Cari.

  8. Berikut hasil pencariannya :

  9. Pada form cetak, klik icon untuk membuka semua list data dalam format PDF atau klik icon untuk mencetak semua list data.
  10. Pada form List Data, klik icon untuk edit data pengolahan pabrik.
  11. Klik icon untuk hapus data pengolahan pabrik.
  12. Klik icon untuk posting data pengolahan pabrik, jika data sudah posting icon akan berubah menjadi dan data tidak dapat diubah ataupun dihapus lagi.
  13. Klik icon untuk melihat data pengolahan pabrik dalam format PDF
