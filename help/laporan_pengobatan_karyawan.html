LAPORAN PENGOBATAN KARYAWAN

Modul : SDM
Tentang : Laporan Pengobatan Karyawan
Isi :

Langkah-langkah melihat Laporan Pengobatan Karyawan yang belum dibayar :

Masuk ke menu, akan terdapat 8 Tab yaitu Tab Rincian, Tab Rank Diagnosa, Tab Rank Biaya/Karyawan, Tab Rank Biaya/Diagnosa, Tab Monthly Trend, Tab By Cost Type, Tab By Treatment Type dan Tab Detail by Employee seperti di bawah ini :

  1. Tab Rincian
    1. Klik Tab Rincian, akan muncul semua rincian pengobatan karyawan.
    2. b. Jika ingin mencari data tertentu dapat menggunakan fasilitas pencarian data berdasarkan Tahun Plafond, Kode Organisasi, Rumah Sakit, dan Nama Karyawan, seperti di bawah ini :

    3. Klik icon untuk menampilkan Laporan Pengobatan Karyawan dalam format Excel.
    4. Klik icon untuk menampilkan detail rincian pengobatan karyawan, seperti contoh di bawah ini:

  2. Tab Rank Diagnosa
    1. Klik Tab Rank Diagnosa, pilih Tahun Plafond dan Kode Organisasi maka akan muncul daftar rank diagnosa berdasarkan kriteria yg dicari, seperti contoh di bawah ini :

    2. Klik icon untuk menampilkan Laporan Rank Diagnosa dalam format Excel.

  3. Tab Rank Biaya/Karyawan
    1. Klik Tab Rank Biaya/ Karyawan, pilih Tahun Plafond dan Kode Organisasi maka akan muncul daftar ranking biaya per karyawan berdasarkan kriteria yang dicari, seperti contoh berikut :

    2. Klik icon untuk menampilkan Laporan Rank Biaya per Karyawan dalam format Excel.

  4. Tab Rank Biaya/Diagnosa
    1. Klik Tab Ranking Biaya/ Diagnosa, pilih Tahun Plafond dan Kode Organisasi maka akan muncul daftar rank biaya per diagnose berdasarkan kriteria yang dicari, seperti contoh berikut :

    2. Klik icon untuk menampilkan Laporan Rank Biaya per Diagnosa dalam format Excel.

  5. Tab Monthly Trend
    1. Klik Tab Monthly Trend, pilih Tahun Plafond dan Kode Organisasi maka akan muncul daftar pengobatan bulanan berdasarkan kriteria yang dicari, seperti contoh berikut :

    2. Klik icon untuk melihat Laporan pengobatan bulanan dalam format Excel.

  6. Tab By Cost Type
    1. Klik Tab By Cost Type, pilih Tahun Plafond dan Nama Karyawan maka akan muncul daftar jenis biaya pengobatan berdasarkan kriteria yang dicari, seperti contoh berikut :

    2. Klik icon untuk melihat Laporan pengobatan berdasarkan jenis biaya dalam format Excel.

  7. Tab By Treatment Type
    1. Klik Tab By Treatment Type, Pilih Tahun Plafond dan Kode Organisasi maka akan muncul daftar jenis perawatan berdasarkan kriteria yang dicari, seperti contoh berikut :

    2. Klik icon untuk melihat Laporan pengobatan berdasarkan jenis perawatan dalam format Excel.

  8. Tab Detail By Employee
    1. Klik Tab Detail By Employee, Pilih Tahun Plafond dan Nama Karyawan maka akan muncul daftar biaya pengobatan per karyawan berdasarkan kriteria yang dicari, seperti contoh berikut :

    2. Klik icon untuk melihat Laporan pengobatan berdasarkan per karyawan dalam format Excel.
