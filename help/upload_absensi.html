UPLOAD ABSENSI

Modul : SDM
Tentang : Transaksi Upload Absensi
Isi :

Langkah-langkah Upload Absensi :

Masuk ke menu, terdapat 2 Tab form yang dapat digunakan yaitu Form Input Manual dan Form Upload Device, seperti tampilan berikut :

  1. Form Input Manual

    2. Pilih Tab Form Input Manual, kemudian akan muncul form sebagai berikut :

    Lengkapi data seperti gambar diatas, setelah selesai klik tombol Simpan.

    Data yang sudah tersimpan akan muncul pada List data di bawah ini :

    Klik icon untuk hapus data absensi karyawan.

  2. Form Upload Device

    3. Pilih Tab Form Upload Device untuk memasukkan data dari Fingerprint.

    Pilih Kode Organisasi dan Tanggal, kemudian klik tombol Preview.

    Sistem akan menampilkan list data kehadiran seperti di bawah ini :

    Klik Tombol Mulai Upload, Sistem akan mengupload data kehadiran secara otomatis.

    Sistem akan memberikan informasi jika proses upload telah berhasil, sebagai berikut :

    Klik OK, Proses selesai.
