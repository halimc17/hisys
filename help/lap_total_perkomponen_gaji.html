LAPORAN TOTAL PER KOMPONEN GAJI

Modul : SDM
Tentang : Laporan Total per Komponen Gaji
Isi :

Langkah-langkah melihat Laporan Total per Komponen Gaji :

Masuk ke menu, akan muncul 2 tab yaitu Tab Rincian per Karyawan dan Tab Rekap per Jabatan, seperti di bawah ini :

  1. Tab Rincian per Karyawan

    2. Pilih nama unit, periode, komponen payroll dan tipe karyawan, kemudian klik tombol Preview untuk menampilkan laporan.

    Laporan ini dapat dibuka dalam format Excel dengan klik tombol Excel di atas.

    Berikut tampilan Laporan Rincian Komponen Gaji per Karyawan :

  2. Tab Rekap per Jabatan

    3. Pilih nama unit, periode, komponen payroll, tipe karyawan dan jabatan, kemudian klik tombol Preview untuk menampilkan laporan.

    Laporan ini dapat dibuka dalam format Excel dengan klik tombol Excel di atas.

    Berikut tampilan dari Laporan Rincian Komponen Gaji per Jabatan :
