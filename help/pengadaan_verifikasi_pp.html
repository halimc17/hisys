Langkah-langkah Verifikasi PP:

  1. Summary
    1. Klik icon untuk melihat summary purchaser. Pilih periode yang akan dilihat :

    2. Untuk melihat detail summary per purchaser klik pada purchaser, berikut tampilannya :

    3. Klik icon untuk melihat detail summary purchaser dalam format Excel.
    4. Klik pada Total Item untuk melihat List Permintaan Barang dalam format Excel.
  2. Tools
    1. Klik icon untuk melihat List Permintaan Pembelian semua PT, berikut tampilannya :

    2. Klik icon untuk melihat List Permintaan Barang semua PT.
    3. Klik pada salah satu PT untuk melihat detail, berikut tampilannya :

    4. Klik pada salah satu PP untuk melihat detail PP, berikut tampilannya :

    5. Verifikasi PP dapat dilakukan pada Form Verivikasi di atas dengan memilih Purchaser dan Lokasi Tugas kemudian klik tombol Simpan Seluruhnya.
    6. Klik icon untuk cetak PP dalam format PDF.
  3. List Data
    1. Klik icon untuk melihat list permintaan pembelian yang membutuhkan verifikasi dari Manager Purchasing. Berikut tampilan List PP :

    2. Verifikasi PP dapat dilakukan dengan klik No.PP, akan muncul Form Verifikasi seperti di bawah ini :

      3. Pilih Purchaser dan Lokasi Tugas kemudian klik tombol Simpan Seluruhnya maka PP ini akan masuk ke list purchaser yang ditunjuk untuk dibuat PO. Untuk penentuan purchaser dan lokasi tugas berdasarkan dengan SOP yang diberlakukan.

    3. Verifikasi PP juga dapat dilakukan dengan mengedit langsung daftar permintaan pembelian dengan klik icon kemudian isi jumlah realisasi dan satuan lalu pilih purchaser dan lokasi tugas seperti di bawah ini :

      4. Klik icon untuk simpan verifikasi PP.

    4. Klik icon untuk melakukan percakapan dengan purchaser dan pembuat PP, berikut tampilan form chat :

      5. Jika sudah terjadi percakapan, maka icon akan berubah menjadi icon
