TRANSAKSI LEMBUR

Modul : SDM
Tentang : Transaksi Lembur
Isi :

Langkah-langkah input Transaksi Lembur :

  1. Masuk ke menu, klik icon untuk membuat transaksi lembur baru. Berikut form header pengisian lembur :

    2. Pilih Unit Kerja dan Tanggal kemudian klik tombol Simpan untuk menyimpan data atau klik tombol Batal untuk membatalkan.

  2. Setelah data header disimpan maka akan muncul form rincian seperti di bawah ini :

    3. Lengkapi data seperti di atas, sebagai catatan ketika memilih Basis Jam Lembur maka Uang Lembur akan secara otomatis mengalikan dari Gaji pokok dengan Jumlah jam lembur yang sebelumnya telah di atur di menu SDM > Setup > Lembur.

    Klik icon untuk menyimpan rincian data, ulangi pengisian jika diperlukan. Setelah selesai klik tombol Selesai untuk mengakhiri proses penginputan.

  3. Rincian data yang sudah tersimpan akan muncul pada form Data Tersimpan di bawah ini :

      • Klik icon untuk edit rincian data lembur.
      • Klik icon untuk hapus rincian data lembur.
  4. Klik icon untuk melihat semua list data lembur.
  5. Terdapat fasilitas pencarian berdasarkan nama perusahan dan/atau tanggal seperti di bawah ini :

    6. Klik tombol Cari untuk melakukan pencarian.

  6. Berikut hasil pencariannya :

  7. Klik icon untuk edit rincian data lembur (data header tidak dapat diedit).
  8. Klik icon untuk hapus data lembur.
  9. Klik icon untuk melihat data lembur dalam format PDF
