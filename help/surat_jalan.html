SURAT JALAN

Modul : Pengadaan
Tentang : Pengiriman Internal/Surat Jalan
Isi :

Langkah-langkah input Surat Jalan :

  1. Masuk ke menu, akan muncul form inputan seperti gambar dibawah ini untuk menginput transaksi Surat Jalan :

  2. Lengkapi data yang dibutuhkan, nomor surat jalan akan terbentuk secara otomatis dan kode organisasi dikunci berdasarkan lokasi tugas pembuat transaksi surat jalan tersebut. Jika form sudah dilengkapi kemudian klik tombol Simpan untuk menyimpan data header surat jalan.

  3. Setelah disimpan, sistem akan menampilkan tombol-tombol untuk memasukkan data detail bisa berdasarkan PO, Package list ataupun Material list.
    1. Berikut tampilan add detail berdasarkan PO :

      2. Pilih No PO yang dimaksud dengan men-centang check box disamping no PO, kemudian klik tombol Add to Detail.

    2. Berikut tampilan add detail berdasarkan No Package List :

      3. Pilih No Package List yang dimaksud dengan men-centang check box disamping no package list, kemudian klik tombol Add to Detail.

    3. Berikut tampilan add detail berdasarkan No Package List :

      4. Pilih nama barang yang dimaksud dengan men-centang check box disamping kode barang, kemudian klik tombol Add to Detail.

  4. Setelah add detail sistem akan menampilkan form detail seperti berikut :

    5. Isi jumlah barang kemudian klik untuk menyimpan data detail.

    Klik icon untuk menghapus data detail

  5. Klik List Data untuk melihat List Transaksi Surat Jalan yang sudah diinput.
  6. Lakukan pencarian data dengan memasukkan no surat jalan pada form pencarian data berikut :

  7. Sistem akan menampilkan data sesuai dengan no surat jalan yang dicari, sebagai berikut :

    • Klik icon untuk edit data Surat Jalan
    • Klik icon untuk menghapus data Surat Jalan
    • Klik icon untuk melihat data Surat Jalan dalam format PDF
  8. Kemudian lakukan posting terlebih dahulu dengan klik tombol posting pastikan sebelum klik tombol posting dokumen sudah lengkap. Jika data sudah diposting maka warna icon berubah menjadi hijau dan kolom release akan terisi nama user yang melakukan posting.
  9. Sebagai catatan untuk kolom franco dan tanggal tiba akan terisi ketika sudah melakukan posting di list data surat jalan dan posting di menu Pengadaan-Transaksi-Pengiriman Internal-Penerimaan Surat Jalan
