INTEGRITY CHECK BKM (SEBELUM TUTUP BUKU)

Modul : Pengadaan
Tentang : Proses Integrity Check BKM
Isi :

Langkah-langkah Proses Integrity Check BKM :

  1. Masuk ke menu, pilih Nama Unit dan Periode, kemudian klik tombol Preview untuk menampilkan daftar no transaksi yang belum terdaftar pada dokumen pengeluaran gudang.

  2. Berikut contoh tampilan dari daftar no transaksi tersebut :

  3. Klik tombol Simpan untuk memproses no transaksi tersebut.
  4. Jika setelah klik tombol Preview sistem menampilkan informasi sebagai berikut, maka semua transaksi BKM telah sesuai dengan dokumen pengeluaran barang.
