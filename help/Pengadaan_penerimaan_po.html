PENCATATAN PENERIMAAN PO

Modul : Pengadaan
Tentang : Pencatatan Penerimaan PO
Isi :

Langkah-langkah Pencatatan Penerimaan PO :

    Masuk ke menu, terdapat 2 tab yaitu Tab Penerimaan Barang dan Tab List Data.

    1. Tab Penerimaan Barang

      2. Lengkapi nama unit, tanggal dan No. PO. klik tombol untuk menampilkan form pencarian No. PO, maka akan tampil gambar berikut :

      Pilih no PO dengan klik pada PO yang diinginkan, no Dokumen dan nama supplier akan otomatis terisi dalam form, setelah selesai klik tombol Tampilkan.

      Kemudian akan muncul detail rincian dari PO tersebut, seperti berikut :

      Input jumlah barang diterima sesuai dengan jumlah di PO kemudian klik tombol Simpan. Setelah selesai dicatat klik tombol Selesai.

    2. Tab List Data

      3. Klik Tab List Data maka akan muncul semua transaksi pencatatan penerimaan PO. Lakukan pencarian data pencatatan penerimaan PO yang dimaksud, seperti tampilan di bawah ini :

      • Klik icon untuk mengubah data pencatan penerimaan PO
      • Klik icon untuk menghapus data pencatatan penerimaan PO
      • Klik icon untuk cetak dokumen pencatatan penerimaan PO
