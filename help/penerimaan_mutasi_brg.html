PENERIMAAN BARANG MUTASI

Modul : Pengadaan
Tentang : Penerimaan Barang Mutasi
Isi :

Langkah-langkah melakukan Penerimaan Barang Mutasi :

Masuk ke menu, akan terdapat form daftar gudang dan 3 tab yaitu tab Barang Datang, tab Penerimaan Mutasi Barang dan tab Sdh.Diterima.

Pilih gudang yang dimaksud, Pemilik Barang akan otomatis muncul kemudian klik Simpan. Tombol Ganti digunakan untuk mengganti pilihan gudang.

  1. Tab Barang Datang

    2. Setelah klik tombol Simpan di atas maka sistem akan menampilkan daftar mutasi barang yang belum diproses, seperti di bawah ini :

    Untuk memproses penerimaan barang mutasi klik icon sistem akan menampilkan form Penerimaan Barang Mutasi.

  2. Tab Penerimaan Mutasi Barang

    3. Input Tanggal barang diterima dan Jumlah barang yg diterima kemudian klik tombol Simpan.

  3. Tab Sdh.Diterima

    4. Klik Tab Sdh.Diterima maka akan muncul transaksi penerimaan barang mutasi yang sudah diproses. Lakukan pencarian untuk transaksi penerimaan barang mutasi yang dimaksud seperti tampilan di bawah ini :

    Berikut hasil pencarian transaksi di atas :

    • Klik icon untuk hapus data penerimaan barang mutasi.
    • Klik icon untuk melihat Penerimaan Barang Mutasi dalam format PDF

    Karena transaksi penerimaan barang mutasi masih belum diposting maka status Penerimaan Barang Mutasi ini masih "Not Confirm", seperti gambar dibawah ini :

    Lakukan proses posting pada menu Pengadaan - Transaksi - Adm. Gudang - Posting untuk mengubah status tersebut menjadi "Confirm".
