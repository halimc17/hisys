LAPORAN ALOKASI DETAIL PEMAKAIAN BARANG

Modul : Pengadaan
Tentang : Laporan Alokasi Detail Pemakaian Barang
Isi :

Langkah-langkah melihat Laporan Alokasi Detail Pemakaian Barang :

  1. Masuk ke menu akan muncul form pencarian laporan alokasi detail pemakaian barang, lengkapi form tersebut seperti contoh berikut :

  2. Jika ingin melihat alokasi detail pemakaian keseluruhan barang, maka kolom Kode Barang dikosongkan, seperti contoh diatas.
  3. Jika ingin melihat detail per barang maka inputkan nama barang dengan klik tombol lalu lakukan pencarian nama barang yang dimaksud kemudian klik pada nama barang tersebut.
  4. Klik tombol Preview untuk menampilkan laporan alokasi detail pemakaian barang, seperti berikut :

  5. Laporan ini juga bisa dilihat dalam format excel dengan klik tombol Excel diatas.
