Langkah-langkah melihat Laporan Summary Progress SPK :

Masuk ke menu, akan muncul 3 form laporan stock seperti di bawah ini :

  1. Laporan Summary Progress SPK
    1. Pilih Perusahaan dan Periode kemudian klik tombol Preview untuk menampilkan laporan :

    2. Berikut tampilan dari Laporan Summary Progress SPK :

      3. Laporan ini dapat dilihat dalam format Excel dengan klik tombol Excel dan format Pdf dengan klik tombol Pdf

  2. Laporan Summary Progress SPK per Tahun
    1. Pilih Tahun dan Nama Kontraktor, kemudian klik tombol Preview untuk menampilkan laporan:

    2. Berikut tampilan dari Laporan Summary Progress SPK per Tahun :

      3. Laporan ini dapat ditampilkan dalam format Excel dengan klik tombol Excel di atas.
