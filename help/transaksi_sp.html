TRANSAKSI SURAT PERINGATAN

Modul : SDM
Tentang : Transaksi Surat Peringatan
Isi :

Langkah-langkah input Transaksi Surat Peringatan :

Masuk ke menu, akan terdapat 2 Tab yaitu Tab Form dan Tab List Data seperti di bawah ini :

  1. Form

      2. Lengkapi data seperti di bawah ini kemudian simpan :

      Klik tombol Simpan untuk menyimpan data.

      Akan muncul konfirmasi seperti di bawah ini :

      Klik tombol OK untuk melanjutkan proses. Akan muncul pesan seperti di bawah ini :

      Klik tombol OK.

  2. List Data
    1. Pada tab ini akan menampilkan list data surat peringatan.
    2. Terdapat fasilitas pencarian berdasarkan nama karyawan yang menerima surat peringatan :

      • Klik icon untuk melihat Surat Peringatan dalam format PDF.
      • Klik icon untuk hapus data surat peringatan.
      • Klik icon untuk edit data surat peringatan.
