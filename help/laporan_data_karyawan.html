LAPORAN DATA KARYAWAN

Modul : SDM
Tentang : Laporan Data Karyawan
Isi :

Langkah-langkah melihat Laporan Data Karyawan :

  1. Masuk ke menu, terdapat 2 pencarian :
    1. Pencarian berdasarkan nama karyawan, lokasi tugas, tipe karyawan, status dan jenis kelamin.
    2. Pencarian berdasarkan tahun masuk, bulan masuk, tahun keluar dan bulan keluar.

  2. Setelah memasukkan kriterian data pencarian, kemudian klik tombol Cari

    3. Berikut tampilan dari data karyawan yang dicari :

      • Klik icon untuk melihat daftar data karyawan dalam format Excel.
      • Klik icon untuk melihat detail data karyawan dalam format PDF.
