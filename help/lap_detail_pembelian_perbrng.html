LAPORAN DETAIL PEMBELIAN PER BARANG

Modul : Pengadaan
Tentang : Laporan Detail Pembelian Per Barang
Isi :

Langkah-langkah melihat Laporan Detail Pembelian Per Barang :

  1. Masuk ke menu, pilih kelompok barang dan nama barang. Nama barang akan langsung dispesifikasikan sesuai dengan kelompok barang yang dipilih.
  2. Nama barang dapat dipilih seluruhnya, atau per barang dengan pilih nama barang yang tampil pada menu pilihan atau dengan klik icon untuk mencari nama barang.

    3. Jika form pencarian laporan sudah dilengkapi, klik tombol Preview untuk menampilkan laporan.

  3. Berikut Laporan Detail Pembelian Per Barang :

    4. Laporan ini dapat dilihat dalam format Excel dengan klik tombol Excel dan klik tombol Pdf untuk melihat laporan dalam format Pdf.
