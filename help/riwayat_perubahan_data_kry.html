LAPORAN RIWAYAT PERUBAHAN DATA KARYAWAN

Modul : SDM
Tentang : Laporan Riwayat Perubahan Data Karyawan
Isi :

Langkah-langkah melihat Laporan Riwayat Perubahan Data Karyawan :

  1. Masuk ke menu, inputkan Nama Karyawan, Jabatan dan Tanggal, kemudian klik tombol Preview.

  2. Berikut tampilan dari Laporan Riwayat Perubahan Data Karyawan :

    3. Laporan ini juga dapat dibuka dalam format Excel dengan klik tombol Excel dan dalam format Pdf dengan klik tombol Pdf di atas.
