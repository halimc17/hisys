RELEASE ORDER PEMBELIAN (PURCHASE ORDER)

Modul : Pengadaan
Tentang : Release Purchase Order (PO)
Isi :

Langkah-langkah Release Purchase Order:

    Masuk ke menu maka akan muncul semua list order pembelian yang belum dilakukan release.

    Dalam menu PO Release ini user dapat melakukan sebagai berikut :

    • Koreksi data PO jika masih tidak sesuai
    • Release PO jika PO disetujui
    • Unrelease PO
    • Tutup PO jika PO tersebut sudah disetujui dan sudah keluar dokumen invoice

  1. Langkah-langkah untuk koreksi data PO

    2. Klik icon untuk melihat rincian detail PO sebagai berikut :

    Pada kolom Koreksi, Inputkan alasan koreksi PO seperti contoh gambar di bawah, Setelah selesai klik tombol Simpan, maka PO tersebut akan kembali ke list kerja pembuat PO untuk dilakukan koreksi.

  2. Langkah-langkah Release PO

    3. Cari data PO yang akan di release, seperti contoh berikut :

    Sistem akan menampilkan data No PO yang dicari

    Kemudian klik tombol Release PO untuk merelease PO yang dimaksud, maka tampilan akan menjadi seperti dibawah:

  3. Langkah-langkah Unrelease PO

    4. Klik tombol Unrelease PO untuk menarik kembali PO yang sudah pernah dirilis, seperti contoh di bawah ini :

    Sistem akan menampilkan konfirmasi proses unrelease, seperti berikut :

    Klik Ok untuk melanjutkan proses unrelease.

  4. Langkah-langkah Tutup PO

    5. Setelah PO telah selesai direlease, untuk menutup transaksi PO tersebut klik tombol Tutup, seperti contoh berikut :

    Maka sistem akan menampilkan form konfirmasi tutup, sebagai berikut :

    Isikan form tersebut kemudian klik tombol Tutup.

    Sistem akan menampilkan konfirmasi proses tutup PO, seperti berikut :

    Klik Ok untuk melanjutkan proses tutup PO.
