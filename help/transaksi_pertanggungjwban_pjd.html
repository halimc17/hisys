TRANSAKSI PERTANGGUNGJAWABAN PERJALANAN DINAS

Modul : SDM
Tentang : Transaksi Pertanggungjawaban Perjalanan Dinas
Isi :

Langkah-langkah input Transaksi Pertanggungjawaban Perjalanan Dinas :

Masuk ke menu, akan terdapat 3 Tab yaitu Tab Form, Tab Hasil kerja dan Tab List Data seperti di bawah ini :

  1. Tab Hasil Kerja
    1. Klik Tab Hasil Kerja, isikan uraian hasil perjalanan dinas seperti contoh berikut :

    2. Klik tombol Simpan untuk menyimpan hasil kerja pertanggungjawaban perjalanan dinas.

  2. Tab Form
    1. Klik Tab Form, lengkapi data seperti gambar berikut :

    2. Setelah input data rincian, klik tombol Simpan
    3. Data yang sudah disimpan akan tampil pada list data
    4. Klik icon untuk menghapus data rincian pertanggungjawaban perjalanan dinas.

  3. Tab List Data
    1. Klik Tab List Data, akan muncul semua list data pertanggungjawaban perjalanan dinas.

      2. Terdapat fasilitas pencarian berdasarkan no.transaksi, klik tombol cari untuk menampilkan data perjalanan dinas yang dicari.

    2. Klik icon yang pertama untuk melihat rincian biaya pada surat perjalanan dinas
    3. Klik icon yang kedua untuk melihat uraian hasil tugas pada surat perjalanan dinas
    4. Klik icon untuk edit rincian pertanggungjawaban perjalanan dinas.
