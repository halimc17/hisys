PEMBUATAN ORDER PEMBELIAN (PURCHASE ORDER)

Modul : Pengadaan
Tentang : Pembuatan Purchase Order (PO) Pusat
Isi :

Langkah-langkah Pembuatan Purchase Order:

  1. Masuk ke menu maka akan muncul semua list job purchaser (list PP per PT) :

  2. Klik jumlah PP per PT di atas, maka akan muncul semua list PP yang harus dibuatkan Purchase Order berdasarkan No. PP ataupun Perbandingan Harga :
    1. Tampilan pembuatan PO berdasarkan No. PP :

      2. Pilih PP (centang kolom Action) yang akan dibuatkan Purchase Order kemudian klik tombol Proses.

    2. Tampilan pembuatan PO berdasarkan No Perbandingan Harga :

      3. Masukkan No perbandingan Harga kemudian tekan tombol Proses.

  3. Berikut tampilan setelah klik Proses:

  4. Jika ingin memasukkan internal memo dalam PO yang dibuat klik tombol Browse diatas kemudian cari file internal memo yang dimaksud lalu klik Open. (format file yang dapat dimasukkan adalah pdf, jpeg, png)

    5. Klik icon untuk menghapus data barang ataupun internal memo.

  5. Lengkapi form tersebut kemudian klik tombol Simpan. Sistem akan kembali pada tampilan daftar PO

    • Klik icon untuk mengubah data PO
    • Klik icon untuk menghapus data PO
    • Klik icon untuk mencetak data PO
    • Klik icon untuk melihat internal memo pada PO
    • Klik icon untuk menghapus internal memo pada PO
