    Untuk membuat transaksi baru click icon dan berikut adalah tampilannya :
    Gambar 2 :

    Note :
    - Kode Pabrikasi : Otomatis terisi setelah tombol Simpan di click
    - Nama Pabrikasi : Nama dari pabrikasi yang akan dibuat
    - Kode Kelompok : Kelompok pabrikasi (sumber dari menu : Pabrikasi - Setup - Kelompok Pabrikasi)
    - Tanggal Order : Range periode order
    - Kode Sales Order : Kode sales order, click untuk melakukan pencarian (sumber dari menu : Pabrikasi - Transaksi - Sales Order)

    Setelah semua terisi kemudian click tombol Simpan, akan tampil form rincian seperti dibawah ini :

    Note :
    - Tahapan : Tahapan dalam pembuatan pabrikasi
    - Tanggal : Tanggal rencana pengerjaan per tahapan
    - Keterangan : Keterangan dari tahapan ini

    Click Simpan jika sudah selesai pengisian dan akan melanjutkan mengisi tahap selanjutnya, click Selesai jika tidak ada lagi tahapan selanjutnya.
