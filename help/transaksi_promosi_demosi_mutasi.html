TRANSAKSI PROMOSI/DEMOSI/MUTASI

Modul : SDM
Tentang : Transaksi Promosi/Demosi/Mutasi
Isi :

Langkah-langkah input Transaksi Promosi/Demosi/Mutasi :

Masuk ke menu, akan terdapat 2 tab yaitu Tab Form dan Tab List Data seperti di bawah ini :

  1. Tab Form

    2. Lengkapi data seperti di bawah ini, lalu klik tombol Simpan untuk menyimpan data:

  2. Tab List Data

    3. Klik tab List Data, untuk melihat daftar promosi/mutasi/demosi. Pada tab list data juga terdapat fasilitas pencarian berdasarkan no. transaksi.

    Input No. Transaksi kemudian klik tombol Cari, seperti contoh di bawah ini :

      • Klik icon untuk melihat surat keputusan promosi/demosi/mutasi dalam format PDF.
      • Klik icon untuk edit data promosi/demosi/mutasi.
      • Klik icon untuk hapus data promosi/demosi/mutasi.
      • Klik icon untuk posting data promosi/demosi/mutasi. Setelah lakukan posting data tidak dapat diubah ataupun dihapus, dan icon posting akan berubah menjadi warna hijau.
